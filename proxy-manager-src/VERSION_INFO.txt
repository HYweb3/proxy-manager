🆘 故障排除:
-----------
如果遇到问题:

1. 检查服务器日志
   sudo journalctl -u proxy-web -n 50

2. 验证文件版本
   grep "new QRCode" /var/www/proxy-manager/proxy_web.py

3. 重启服务
   sudo systemctl restart proxy-web

4. 清除浏览器缓存
   Ctrl+Shift+Delete
